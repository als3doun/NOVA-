# NOVA | نوفا لتنظيم الحياة

تطبيق ويب عربي (RTL) لتنظيم المهام والأهداف والكتب والمحاضرات والمشاريع، من السنة إلى اليوم.
ملف واحد بلا مكتبات ولا خطوات بناء: `index.html`.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub، ثم ارفع جميع ملفات هذا المجلد إلى الفرع `main`.
2. من **Settings ← Pages** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط Save.
3. بعد دقائق يظهر الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`

## التثبيت على الجوال أو الكمبيوتر
افتح الرابط في المتصفح ثم اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق». يعمل بعد ذلك دون إنترنت (عدا خط Google Fonts الذي يعود إلى خط النظام عند غياب الاتصال).

## البيانات
- تُحفظ في `localStorage` داخل متصفح كل جهاز، ولا تُرفع إلى أي خادم.
- لا توجد مزامنة بين الأجهزة. استخدم **الإعدادات ← نسخ احتياطي واستعادة** لنقل بياناتك.
- مسح بيانات المتصفح يحذف بيانات التطبيق، فاحتفظ بنسخة احتياطية دورية.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملًا |
| `manifest.json` | بيانات التثبيت (PWA) |
| `sw.js` | العمل دون اتصال |
| `icon.svg` | أيقونة التطبيق |
| `.nojekyll` | يمنع معالجة Jekyll على Pages |

## التطوير محليًا
افتح `index.html` مباشرة، أو شغّل خادمًا بسيطًا لاختبار PWA: `python3 -m http.server`
